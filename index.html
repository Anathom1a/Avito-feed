Инструкция: Как настроить хостинг XML-фида на GitHub для Авито

Полное руководство по размещению вашего фида на GitHub Pages и связке с личным кабинетом Авито Автозагрузки.

1

Создайте репозиторий на GitHub

1. Перейдите на github.com/new.

2. Укажите имя репозитория, например: avito-feed.

3. Выберите тип: Public (публичный репозиторий необходим для бесплатного GitHub Pages).

4. Нажмите «Create repository».

2

Загрузите файлы проекта

Загрузите в корень репозитория файл avito_feed.xml и данный редактор index.html:

  • Через веб-интерфейс: Нажмите «Add file» → «Upload files» → перетащите файлы и нажмите «Commit changes».
  • Через прямое подключение в этом редакторе: Нажмите кнопку «Публикация в GitHub» в правом верхнем углу, введите ваш Personal Access Token и нажмите «Опубликовать» — файл загрузится автоматически!
3

Включите GitHub Pages (получите постоянную ссылку)

1. В вашем репозитории перейдите во вкладку Settings (Настройки) → слева раздел Pages.

2. В блоке Build and deployment выберите:

  • Source: Deploy from a branch
  • Branch: main (или master), папка: / (root)

3. Нажмите Save. Через 1-2 минуты GitHub опубликует ваш фид.

Ваша ссылка для Авито будет иметь вид:
https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/avito_feed.xml
4

Подключите ссылку в кабинете Авито

1. Зайдите в кабинет Авито для бизнеса → раздел «Автозагрузка» → «Настройки».

2. Выберите способ загрузки: «По расписанию» (или «По ссылке»).

3. Вставьте вашу ссылку на GitHub Pages (из шага 3).

4. Настройте время автозагрузки (например, ежедневно в 09:00 и 18:00) и введите email для отчетов об обработке.

5. Нажмите «Сохранить». Авито скачает фид, проверит объявления и начнет автопубликацию!

Почему именно GitHub Pages, а не raw.githubusercontent.com?

• Корректный заголовок: GitHub Pages отдает Content-Type: application/xml; charset=utf-8, что гарантирует мгновенное распознавание валидатором Авито без предупреждений о типе файла.
• Без ограничений скорости: GitHub Pages работает на глобальном CDN (Fastly), где отсутствуют жесткие ограничения на скачивание роботами-парсерами.
• Мгновенное обновление: Как только вы коммитите изменения в файл, они появляются в течение 30-60 секунд.
