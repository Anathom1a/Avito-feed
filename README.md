## 1. Архитектура и хостинг на GitHub

Сервис **«Авито Автозагрузка»** поддерживает синхронизацию объявлений по расписанию через прямую HTTP/HTTPS ссылку на XML-файл.

### Почему GitHub — идеальное решение:
- **Бесплатно 24/7:** Не нужно оплачивать VDS, хостинги или подписки на сторонние сервисы автозагрузки.
- **Глобальный CDN:** Быстрая отдача файла роботу Авито из любой точки РФ без сбоев.
- **Версионирование (Git):** Всегда можно посмотреть историю изменений, откатиться назад или увидеть, кто и когда вносил правки.

### GitHub Pages vs GitHub Raw:
| Параметр | GitHub Pages (Рекомендуется ⭐) | GitHub Raw |
| :--- | :--- | :--- |
| **URL** | `https://<username>.github.io/<repo>/avito_feed.xml` | `https://raw.githubusercontent.com/<user>/<repo>/main/avito_feed.xml` |
| **Content-Type** | `application/xml; charset=utf-8` (валидный XML) | `text/plain` |
| **Кэширование** | Мгновенно после деплоя (30-60 сек) | Кэш до 5-10 минут |
| **Лимиты скачивания** | Высокие лимиты через CDN Fastly | Возможен rate-limit при частых обращениях |
| **Веб-интерфейс** | Работает прямо в браузере по ссылке | Недоступен |

## 2. Пошаговая настройка хостинга на GitHub Pages

### Шаг 1: Создание репозитория
1. Войдите в свой аккаунт на [GitHub](https://github.com/) и создайте новый репозиторий: [github.com/new](https://github.com/new).
2. Задайте имя, например `avito-feed`.
3. Установите тип **Public** (для бесплатной работы GitHub Pages).
4. Нажмите **«Create repository»**.

### Шаг 2: Загрузка файлов
Загрузите все файлы из этого проекта (`index.html`, `ads_data.js`, `avito_feed.xml`, папку `tools/`, `.github/`):
```bash
git init
git add .
git commit -m "Initial commit: Avito XML Feed & AviFeed Editor"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/avito-feed.git
git push -u origin main
```
*(Или просто перетащите файлы через кнопку «Add file» → «Upload files» в веб-интерфейсе GitHub).*

### Шаг 3: Включение GitHub Pages
1. В репозитории откройте вкладку **Settings** → слева раздел **Pages**.
2. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (или `master`), папка `/ (root)`
3. Нажмите **Save**.
4. Через 1-2 минуты ваш фид и редактор станут доступны по адресам:
   - **Веб-редактор:** `https://<ВАШ_ЛОГИН>.github.io/avito-feed/`
   - **Ссылка на XML фид для Авито:** `https://<ВАШ_ЛОГИН>.github.io/avito-feed/avito_feed.xml`

## 3. Подключение фида в личном кабинете Авито

1. Зайдите в личный кабинет **Авито Pro** (Авито для бизнеса).
2. Перейдите в раздел **«Автозагрузка»** → **«Настройки»**.
3. В блоке **«Способ загрузки»** выберите **«По расписанию»** (или «По ссылке»).
4. В поле **«Ссылка на файл»** вставьте:
   ```text
   https://<ВАШ_ЛОГИН>.github.io/avito-feed/avito_feed.xml
   ```
5. Задайте удобное расписание синхронизации (например, 2-4 раза в день) и email для уведомлений.
6. Нажмите **«Сохранить»**.
7. Авито скачает фид, проверит синтаксис и опубликует/обновит объявления.

## 4. Веб-редактор AviFeed (`index.html`)

Веб-редактор работает полностью автономно в браузере (SPA) и доступен как онлайн по ссылке GitHub Pages, так и локально (двойным кликом по `index.html`):

### Ключевые возможности:
- **База объявлений:** Все 295 объявлений по 85 городам уже загружены.
- **Умный поиск и фильтры:** Поиск по городам, Id, AvitoId, номерам телефонов, статусу наличия прайса.
- **Массовый выбор:** Выбор всех объявлений или отдельных строк чекбоксами.
- **Прямая публикация в GitHub:** Встроенная интеграция с GitHub REST API — сохраняйте изменения прямо в репозиторий в 1 клик без консоли!
- **Валидатор фида:** Проверка корректности структуры перед отправкой на Авито.

## 5. Инструкция: Массовое обновление ФОТО

### Вариант А: Использование фото, размещенных прямо в вашем GitHub-репозитории (Бесплатно)
1. Создайте в репозитории папку `images/` и загрузите туда ваши фотографии: `1.jpg`, `2.jpg`, `3.jpg` ...
2. Ссылки на фото будут постоянными и общедоступными:
   ```text
   https://<ВАШ_ЛОГИН>.github.io/avito-feed/images/1.jpg
   https://<ВАШ_ЛОГИН>.github.io/avito-feed/images/2.jpg
   ```
3. Откройте в редакторе вкладку **«Массовое обновление Фото»**:
   - Вставьте новые ссылки в поле ввода (разделитель `|` или с новой строки).
   - Ознакомьтесь с предпросмотром миниатюр.
   - Нажмите **«Применить ко ВСЕМ 295 объявлениям»** (или к выбранным).
   - Нажмите **«Опубликовать в GitHub»** (или скачайте обновленный `avito_feed.xml`).

### Вариант Б: Умная ротация и перемешивание (Anti-Duplicate)
Чтобы объявления в 85 городах не склеивались фильтрами Авито и выглядели уникально:
- Нажмите **«Перемешать фото 2-9 во всех объявлениях»**: первое главное фото (обложка) останется на месте, а порядок остальных фотографий случайным образом перемешается индивидуально для каждого города.
- Нажмите **«Сдвинуть главное фото на следующее (+1)»**: обложка автоматически сменится на следующую в галерее.

### Вариант В: Распределение фотосетов
Если у вас заготовлено несколько разных комплектов фотографий (например, 5 разных фотосетов):
- Вставьте их в поле «Распределение наборов фото» (по одному набору на строку).
- Редактор циклически распределит их между всеми 295 объявлениями!

## 6. Инструкция: Добавление и настройка ПРАЙС-ЛИСТА (PriceList)

Тег `<PriceList>` в автозагрузке Авито формирует интерактивный прайс-лист услуг прямо в карточке объявления.

### Формат строки услуги в Авито:
```text
Услуга|Описание|Цена|ЦенаОт|ТипСтоимости
```
- **Услуга:** Название (например, `Установка Windows` или `Установка офисных программ`)
- **Описание:** Дополнительные детали (можно оставить пустым `||`)
- **Цена:** Число в рублях (например, `500`, `1000`)
- **ЦенаОт:** `Да` (если цена «от») или `Нет`
- **ТипСтоимости:** `за услугу`, `за час`, `за единицу`, `за выезд`, `за день`

### Как добавить прайс-лист ко всем объявлениям:
1. Откройте вкладку **«Конструктор Прайс-Листа»**.
2. Выберите готовый пресет (например, **«Пресет: Компьютерная помощь»**) или добавьте свои услуги и цены в интерактивную таблицу.
3. Нажмите **«Применить прайс ко ВСЕМ 295 объявлениям»**.
4. Готово! Все объявления получат структурированный блок прайс-листа в формате CDATA:
   ```xml
   <PriceList><![CDATA[Установка операционной системы Windows / macOS||1000|Да|за услугу
   Установка офисных программ (MS Office, Word, Excel)||500|Да|за услугу
   Установка графических программ (Photoshop, CorelDRAW)||700|Да|за услугу
   Установка программ видеомонтажа (Premiere, DaVinci)||800|Да|за услугу
   Установка САПР и 3D-программ (AutoCAD, 3ds Max, Archicad)||1200|Да|за услугу
   Настройка ЭЦП, КриптоПро и сертификатов для торгов и ФНС||1000|Да|за услугу
   Удаленная компьютерная помощь и диагностика||500|Да|за услугу]]></PriceList>
   ```

## 7. Консольные утилиты Python (CLI)

Для автоматизации на сервере или локальной пакетной обработки в папке `tools/` подготовлены готовые скрипты:

### 1. Конвертация Excel в XML:
```bash
python3 tools/excel_to_xml.py -i ads.xlsx -o avito_feed.xml
```

### 2. Пакетное обновление фото:
```bash
# Замена фото на новый список во всех объявлениях:
python3 tools/update_photos.py -i avito_feed.xml -o avito_feed.xml -u "url1 | url2 | url3"

# Случайное перемешивание фото для уникализации по городам:
python3 tools/update_photos.py -i avito_feed.xml -o avito_feed.xml --shuffle
```

### 3. Пакетное обновление прайс-листа:
```bash
python3 tools/update_pricelist.py -i avito_feed.xml -o avito_feed.xml -f default_pricelist.txt
```

### 4. Проверка фида на валидность:
```bash
python3 tools/validate_feed.py avito_feed.xml
```

### 5. Обратный экспорт XML в Excel:
```bash
python3 tools/xml_to_excel.py -i avito_feed.xml -o avito_ads.xlsx
```

```text
│   ├── update_pricelist.py     # Пакетное обновление прайс-листа

├── default_pricelist.txt       # Шаблон прайс-листа услуг компьютерной помощи
├── index.html                  # Веб-приложение редактора (SPA)

```

Разработано для профессиональной работы с Авито Автозагрузкой.
